# タスク一覧: game-core(こいこい対局エンジン)

> 対応する設計: [design.md](./design.md)
> 進め方: 上から順に1タスクずつ。完了したら `[x]` を付ける。

- [ ] 1. 型定義と札データ
  - `types.ts` / `cards.ts`。48枚(光5・タネ9・短冊10・カス24)とテスト
  - _要件: 1-1_
- [ ] 2. シード付き乱数と配札
  - `rng.ts`(mulberry32+shuffle)。配り直し条件(場四・手四)を含む配札とテスト
  - _要件: 1-2, 1-3, 1-4_
- [ ] 3. 役判定
  - `yaku.ts`。全役の判定と文数計算。役ごとの単体テスト
  - _要件: 3-1_
- [ ] 4. 局の状態機械
  - `match.ts` の reducer(playCard/chooseTarget/declareKoikoi/declareShobu)。
    手番進行・めくり・流局・親交代のテスト
  - _要件: 2-1〜2-6_
- [ ] 5. 精算と賭場戦
  - レート・局倍率・こいこい料・旬ボーナス・飛び・場代・撤退・首賭け。
    精算例(仕様書の数値例)をそのままテスト化
  - _要件: 3-2〜3-6, 4-1〜4-4_
- [ ] 6. 細工フック機構
  - `effects.ts`。フック発火+金鍍金・呪い・賽の目の3種とテスト
  - _要件: 5-1〜5-4_
- [ ] 7. 対AI
  - `ai.ts`。打牌選択・こいこい判断・性格パラメータ。決定論性のテスト
  - _要件: 6-1, 6-2_
- [ ] 8. 対局画面(最小)
  - `/match` ルートと `MatchPage`。AI と1局〜賭場戦を遊べる最小UI
  - _要件: 全要件の疎通確認_
